## Report

Comment 0 (reporter):

> If I record capital gains on a stock/fund sale as recommended by the user
> guide, or as implemented by the lots tool, the advanced portfolio report
> counts those gains in the "income" field (twice!).

> Running the advanced portfolio report on this file, Income should be $0, and
> Total Return should be 0.15%. Instead, Income is $5 and Total Return is 0.29%.

Comment 2 (Geert Janssens) asked for a retest on 2.4.13, the latest stable
release, and suspected "the sign reversal was fixed".

Comment 3 (reporter, on 2.4.13). By then Total Return had become an amount
and Rate of Return a percentage (see `93535c955` in [History.md](History.md)):

> The behavior is the same, except "Total Return" is now $10 and "Rate of

Comment 4 (Richard Ullger) confirmed the patch on 2.4.13: "Any capital gain is
correctly recorded in the realised gain column and not in the income column."

Comment 5 (Geert Janssens): "I have now committed the patch as r23309 (trunk)

## The fix

```diff
@@ -514,7 +514,7 @@
 	 ((and (same-account? current (xaccSplitGetAccount x))
 	       (gnc-numeric-zero-p (xaccSplitGetAmount x))
 	       (not (gnc-numeric-zero-p (xaccSplitGetValue x))))
-	  (dividendcoll 'add commod-currency (xaccSplitGetValue x)))
+	  (dividendcoll 'add commod-currency (gnc-numeric-neg (xaccSplitGetValue x))))
```

A split in the stock account with zero shares and a non-zero value was added
to income. The gain split has a positive value in the stock account, so the
gain was counted as income. The patch negates it, which presumably cancels the
same amount being counted again from the paired income split. The loop that
held this line was rewritten in 2014 (`e842f0e75` and the commits after it).
Today the behavior is set by the documented rule that realized-gain splits are
ignored (see [Docs.md](Docs.md#capital-gains)).

Accounts: `Assets:broker account` (ASSET, USD), `Assets:ATT` (STOCK,
commodity `T`, a sibling of the broker account), `Income`,

| 2013-10-10 | buy | ATT +100 sh, value $3415.00; broker -$3415.00 |

| Column | Value | Why |
